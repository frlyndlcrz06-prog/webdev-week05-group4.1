# Vehicle Rental Tracker — OOP Mini-Program

A small PHP OOP mini-program demonstrating classes, an interface, namespaces,
and Composer's PSR-4 autoloading.

## Structure

```
vehicle-rental-tracker/
├── composer.json
├── index.php
├── src/
│   ├── Interfaces/
│   │   └── Rentable.php     # interface: isAvailable()
│   └── Models/
│       ├── Vehicle.php      # implements Rentable
│       └── RentalRecord.php
└── vendor/                  # generated by Composer
```

## Classes

- **Vehicle** (`App\Models\Vehicle`) — implements `Rentable`. Holds plate number,
  model, daily rate, and rental status. `computeRentalCost($days)` applies a
  10% discount for rentals of 7+ days.
- **RentalRecord** (`App\Models\RentalRecord`) — links a renter's name to a
  `Vehicle` and a rental duration. `generateReceipt()` builds a formatted
  summary string.
- **Rentable** (`App\Interfaces\Rentable`) — interface requiring
  `isAvailable(): bool`.

## How to run

```bash
composer dump-autoload   # regenerate vendor/ if needed
php index.php
```
